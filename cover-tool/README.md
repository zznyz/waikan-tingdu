# 封面生成器（老师版）

打开即用：https://zznyz.github.io/waikan-tingdu/cover-tool/

左边填空，右边实时出图，点一下下载。不装软件、不联网、不用会写代码。手机和电脑都能用。

三种封面：外刊 feed 封面（1080×1440）· 贴图号封面（1080×1440）· 公号头图（1410×600）。

> 源码与回归脚本不在本仓库，在 `marketing-playbook/covers/tool/`
> （`tool-template.html` → `build_tool.py` → `selftest.sh`）。**这里的 index.html 是产物，别手改。**
